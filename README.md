# Calculative Foundation Project

## Overview

This project is based on statistical analysis using Python.  
The project includes hypothesis testing, confidence interval calculation, correlation, covariance and data visualization.

The main purpose of this project is to understand practical implementation of statistical concepts used in Data Science and AI/ML.
